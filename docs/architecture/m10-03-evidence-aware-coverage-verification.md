# M10-03 verification record

## Scope and contracts

This change derives product-specific, version-pinned framework coverage from M10-02 controls and M8 evidence versions. Evidence-backed coverage means one active product-applicable implemented control has a currently valid linked evidence version. It is not a legal conformity or certification claim. Structural Part headings remain navigable and do not enter the denominator; numbered clauses, including parent clauses, do.

- Shared wire contracts: `packages/contracts/src/frameworks/schemas/control.schema.ts` and parsed types under `packages/contracts/src/frameworks/types`.
- API boundary: `apps/api/src/frameworks/controls.controller.ts` → application use cases/port → Supabase adapter.
- Database boundary: additive M10-03 migration after M10-02; applicability, recalculation state, and derived requirement rows stay scoped to organization, product, pack, and version.
- Browser boundary: `apps/web/app/_features/frameworks/controls.api.ts` → functional framework workspace and coverage panel.

## Migration and rollback

Apply the ten additive `20260924101931` through `20260924105933` M10-03 migrations after M10-02, regenerate both database type copies with `pnpm --filter infrastructure run db:types`, deploy the API and web, and run `pnpm --filter api run worker:framework-coverage`. Existing selected product/framework scopes are backfilled without changing M7 snapshots or historical source versions. Roll back application behavior by deploying the previous API/web binaries while retaining the additive tables and audit history; do not drop coverage or applicability records or reset data. The worker is restartable and idempotent.

## Residual risks

The repository-wide export registry architecture test still flags 57 M7–M9 tenant tables that predated this change. Those source and restore contracts require separate owner review; this feature adds no missing M10-03 table to that list. The existing Nest controller's whole-file branch measure is 59.64% because emitted decorator branches are counted; its line/function measures are 97.26%/100% and the new routes have focused behavior tests. The bounded local read sample does not prove production or large-tree latency. Coverage invalidation is deliberately conservative for some organization-wide control/evidence changes, so the worker may recalculate more scopes than strictly affected. A current coverage state reports evidence availability, not legal conformity.
