## Implemented changes

- Stream immutable storage downloads through the installed SDK's `asStream()` API; verify hash/size at EOF and cancel upstream on abandonment.
- Validate production ingestion against locally pinned schemas before publishing a graph. Private bounded temporary files enable repeated streaming validation/normalization passes. Invalid originals remain retained with structured reports.
- Repair JSON/XML/tag-value normalization limits, chunk handling, backpressure and diagnostic totals. New graphs record normalizer `m3-03.3` (native CycloneDX license IDs/expressions included); historical graphs remain unchanged.
- Freeze completed normalized graphs, retain narrowly scoped derived identity materialization and authorized organization purge, and restrict retained-table service-role privileges.
- Add parsed, scoped normalized CycloneDX 1.6/SPDX 2.3 exports. CycloneDX may include reviewed M5 VEX; unsupported SPDX VEX and unrepresentable findings fail explicitly.
- Bound browser hashing, preserve upload command identities across lost responses, require manual retries, paginate history and partition caches by organization. Confirmed completions clear the cached command so reselecting a file starts a new command. Replaying initialization for an already verified original returns `upload: null`, then replays completion without signing or overwriting stored bytes.
- Qualify declared dependency evidence; a supplied graph does not establish a complete inventory or legal conformity.
- Integrate installed M4 ecosystem version ordering into new lineage reports without rewriting historical report policies. Live finding deltas require independently ready active feed epochs; a vector/default timestamp cannot silently stand in for a ready feed.
- Evaluate new enabled BSI assessments from verified immutable originals against the pinned 2.0 technical rules. Record evaluator identity, original hash and complete passed/failed/manual-review counts. Conditional facts, build inventory, linked BOMs, license matching and current-edition applicability require human review. Unavailable readers report unavailable; engineering aggregate scoring remains separate. Historical subset reports remain labelled legacy and unchanged. Profile findings have stable bounded identities and exact JSON/XML component locations; byte-bounded details retain complete outcome counts. Exhausted failed predecessors remain readable and no longer block later quality assessments.
- Project validation for verified same-content aliases with their own metadata warnings; preserve canonical reports. Repair quality GET strict parsing by removing only the known internal baseline comparison field. New baseline claims retain fractional scores; historical recorded scores are retained. Non-regression read projections omit improvement-only dimensions to match the frozen wire contract while retaining score deltas and internal comparison facts.

## Compatibility and deployment limits

CycloneDX XML streaming validation requires `xmllint` (`libxml2-utils` on Linux). CI installs it; worker deployments must supply it too. XML validation runs with network access disabled and a pinned local catalog. The SPDX license companion XSD comes from the already locked CycloneDX dependency; see [streaming validation runtime](../../apps/api/src/sboms/validation/STREAMING-VALIDATION.md) for provenance and hash. Missing native validation is retryable unavailability, never acceptance.

The BRD requests SPDX 3.0 tag-value, but SPDX 3 uses JSON-LD. The implementation rejects unsupported representations rather than inventing a normative format. SPDX 3 JSON remains the documented pinned package-SBOM profile. The complete 20-page BSI TR-03183-2 v2.0.0 PDF is available in local working artifacts, SHA-256 `20db4a9e5bfe1d5168e212bd9f3c427a014b3732a061216992e30ceb365ac226`. The failed later publisher fetch did not remove the previously downloaded copy. The whole source has now been reviewed; its PDF is not redistributed in this repository. Aggregate engineering checks remain separate from the pinned technical profile. Technical field failures and manual-review unknowns are explicit; no report establishes current-edition, full BSI or statutory conformity. No invented normative clauses or standard text were added.

Composite graphs preserve evidenced provenance and existing declared edges. A synthetic aggregate root does not establish unreported direct dependencies; no edges are fabricated. Export is a bounded in-memory serialization (50,000 components, 250,000 edges, 50 MiB output); ingestion remains streamed. Temporary spool files are removed on ordinary completion/failure; process death can leave private unreferenced files, requiring scoped operational cleanup after checking active workers.
