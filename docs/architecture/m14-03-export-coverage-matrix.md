# M14-03 export coverage matrix

120 registered source views. This inventory covers actual production lists and nested histories/queues, not every API collection. A registered contract is not proof that its database/UI integration passes; the completion gate must reconcile every row with live parity and browser evidence.

Default scope is all_filtered. Page and selected scopes are advertised only when the owning rendered view supports them. Approved columns below are literal whitelists; no raw source JSON, credentials, storage keys, or signed tokens are export columns. Typed cell definitions are in feature-first source schema files. Source permissions are necessary but source-owned tenant/product/row checks and required roles remain authoritative. Portal context derives hidden request/grant identifiers from verified sessions.

Excluded with evidence: audit.detail_chain is event metadata in audit-detail-panel.tsx, not a rendered collection; technical_file.source_review_history exists in source responses but has no rendered production list. Unrendered connector identity API rows and run-level dead-letter aliases are excluded: connector-detail-content.tsx has no identity collection; connector-dead-letters-section.tsx renders dead_letter_records. Framework upgrade_review is persistence behind the rendered upgrade_preview, not a separate list. Risk requirement references in risk-register-workspace.tsx are assignment controls and counts, not a rendered collection. Also exclude assignment/mention pickers, pure forms, demo/MSW commerce tables and unrendered API collections. Custom requirements preview exports the saved server-owned draft only, never unsaved browser text.
