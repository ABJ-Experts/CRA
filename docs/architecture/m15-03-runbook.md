6. Configure explicit certificate fingerprint grants with stable principal UUID, monotonic grant revision, instance IDs and **instance/tenant tuple scopes**. 7. Start `worker:operator-registry` with separately mounted worker credentials and existing local public licence trust. The scheduler runs every 30 seconds; configured remote targets have an explicit per-target cadence (default/minimum 60 seconds) and a 20-second cycle budget. Use longer target cadences for large scopes; incomplete work retains previous observation timestamps rather than claiming a whole-fleet refresh. Local observation is opt-in. Remote collection is opt-in and accepts only configured private literal HTTPS endpoints with target CA/client certificates; redirects, public fallback and call-home are absent. Never mount the worker credential in ingress. Public issuer verification keys are sufficient; issuer signing keys do not ship.

## Trust, revocation and observation semantics

Replace grant files atomically with a private deployment write. Each request, including reused TLS connections, rereads and validates current grants; removing a fingerprint revokes subsequent requests. Restart for CA/server TLS trust replacement. Replace static assets and restart the listener together because its CSP includes the exact exported hydration script hashes.

The service-only publication is atomic latest-observation persistence, not a regulatory/security audit authority. Operator disclosures use the separate transactional M13 read receipt. The registry is diagnostic latest-observation metadata, never authorization, regulatory approval or a licence grant. Source, attempt, receipt and last-success times have different meanings. Collection failure retains prior source/success timestamps. A configured instance that has never succeeded appears unreachable with null provenance/version/licence; a connection attempt cannot fabricate health. Repeated/out-of-order data cannot advance source freshness.

Customer probes cancel real transport after 250 ms, run at most four concurrently and share a 900 ms post-authentication budget. Dependency failures degrade independently. Explicit identity/permission revocation denies the entire response. Public `/api/v1/health` and `/health/ready` retain their original minimal contracts. M6 detail is stale after 120 seconds without rewriting deadline authority. Feeds retain each source's configured seconds threshold.

Queue units are jobs. Each state count is bounded at 10,000 and becomes `at_least` at the cap. Waiting human review and uncertain external outcomes are separate. Zero queue depth is not a worker heartbeat. Storage units are exact bytes: admitted customer and exempt protected accounting are not free disk, physical file existence or checksum assurance. Evidence archiving does not recover missing bytes. Authenticated evidence access/export remains separately authorized under expiry and exhausted quotas.

## Recovery and rollback

On stale/unreachable sources, inspect the source service and timestamps; do not rewrite them as current or relax permissions. Restore local connectivity without deleting objects. In this development checkout, original Kong expects Docker alias `supabase_storage_cra`; the healthy `supabase_storage_cra_cli_m15` container was reconnected to its existing network with that alias and `storage`, restoring bucket HTTP 200 without changing volumes/files.

Disable the opt-in collector/observer/listener and remove the new UI entry if rollback is needed. Retain registry observations, source ledgers and M13 evidence. The narrow role may be disabled/revoked through explicit deployment; do not remove audit facts or silently disable M15-01/02 enforcement. Existing liveness/readiness, auth, deadline timers and evidence exports remain available. No downgrade deletes customer data.

Local test certificates and disposable fixture data are not deployment credentials. Destroy only the recorded task-owned clone containers/volumes after capturing evidence, keeping the original `cra` stack and unrelated browser origins intact. Missing historical physical bytes cannot be reconstructed from accounting metadata; the previously identified 101 retained sources remain a separate known limitation.
