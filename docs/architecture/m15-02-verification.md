## Contracts and request path

The [licensing usage schemas](../../packages/contracts/src/licensing/schemas/usage.schemas.ts) pin four definitions, current-state periods, source-change reset rules, nullable unknown values, finite/unlimited/unverified/exempt limits, exact safe integers and verified-state time consistency. [Wire types](../../packages/contracts/src/licensing/types/usage.types.ts) derive from `z.output`.

[LicensingGateway](../../apps/web/app/_features/licensing/licensing-gateway.ts) supplies outgoing and incoming schemas to the shared transport. The functional [usage section](<../../apps/web/app/(workspace)/organization/organization-usage-section.tsx>) uses tenant/user/permission-scoped [queries](../../apps/web/app/_features/licensing/licensing.queries.ts). [LicensingUsageController](../../apps/api/src/licensing/licensing-usage.controller.ts) parses strict bodies/queries and declares successful response schemas. [LicenseUsageService](../../apps/api/src/licensing/application/license-usage.service.ts) combines verified local policy with one coherent observation and licence/meter versions; the [Supabase adapter](../../apps/api/src/licensing/infrastructure/supabase-license-usage.repository.ts) parses tenant-first RPC outcomes. Pure [diagnostics](../../apps/api/src/licensing/domain/usage-diagnostics.ts) use exact arithmetic for 80%, equality, zero-cap and overflow cases.

`GET /api/v1/licensing/usage` and `POST /api/v1/licensing/usage/export` require `can_view_licensing`. Reconciliation requires `can_manage_licensing`. All three are protected diagnostic/maintenance operations. Export and reconciliation use current transactional permission checks and actor/tenant/request-bound M13 receipts. The [M13 register](m13-01-operation-register.json) and [licensing register](m15-01-operation-register.json) include the routes.
